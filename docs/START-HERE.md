# ابدأ من هنا — من تحميل الملف إلى منصة تعمل على الإنترنت

دليل خطوة بخطوة. نفّذ الخطوات بالترتيب ولا تتخطَّ أي واحدة.
الوقت المتوقع: من 45 دقيقة إلى ساعة. التكلفة: **صفر**.

**نهاية الطريق:** رابط مثل `https://midar.onrender.com` يعمل من أي جهاز، ولوحة خاصة بك تنشئ منها اشتراكات المدارس.

---

## سؤال أول: ألم نربط البيانات في Firebase؟

لا. ما ربطناه في Firebase هو **التحليلات فقط** (عدد الزيارات)، وهي مجانية وتعمل مع أي استضافة.

أمامك طريقان لتشغيل المنصة، والكود واحد في الاثنين:

| | مجاني (هذا الدليل) | Firebase |
|---|---|---|
| قاعدة البيانات | Neon | Cloud SQL |
| الخادم | Render | Cloud Functions |
| التكلفة | صفر | 15 إلى 30 دولارًا شهريًا |
| بطاقة بنكية | غير مطلوبة | مطلوبة (خطة Blaze) |

ملفات Firebase موجودة في المشروع وجاهزة، فإذا أردت الانتقال لاحقًا لن تحتاج تعديل سطر واحد، فقط أوامر النشر. **الآن نمشي بالطريق المجاني.**

## الخطوة 1: تجهيز جهازك (10 دقائق)

1. **فك ضغط الملف:** اضغط يمين على `midar.zip` ← استخراج. ستحصل على مجلد اسمه `midar`. ضعه في مكان واضح:
   - ويندوز: `C:\midar`
   - ماك: `/Users/اسمك/midar`

2. **ثبّت Node.js:** ادخل `nodejs.org` ونزّل نسخة **LTS** (22 أو أحدث)، ثم ثبّتها بالضغط التالي حتى النهاية.

3. **ثبّت Git:** من `git-scm.com/downloads`.

4. **افتح نافذة الأوامر داخل مجلد المشروع:**
   - ويندوز: افتح مجلد `midar`، اكتب في شريط العنوان `cmd` واضغط Enter.
   - ماك: افتح Terminal واكتب `cd ` ثم اسحب مجلد `midar` إلى النافذة واضغط Enter.

5. **تأكد أن كل شيء تمام** — اكتب:
   ```
   node -v
   git --version
   ```
   يجب أن يظهر رقم النسخة في كل سطر. إذا ظهر خطأ، أعد تثبيت البرنامج وافتح نافذة أوامر جديدة.

## الخطوة 2: قاعدة البيانات على Neon (10 دقائق)

1. ادخل `neon.com` ← **Sign up** ← سجّل بحساب GitHub (بدون بطاقة بنكية).

2. **Create project:**
   - Project name: `midar`
   - Region: اختر الأقرب (مثل Frankfurt)
   - اضغط **Create**

3. ستظهر لك نافذة **Connection string**. اضغط زر النسخ، والصقها في ملف نصي مؤقت. شكلها هكذا:
   ```
   postgresql://neondb_owner:كلمة-سر-طويلة@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
   **سمِّ هذا في ملفك: رابط المالك.**

4. من القائمة الجانبية اضغط **SQL Editor**، والصق هذا الأمر بعد تغيير كلمة المرور إلى كلمة قوية من اختيارك، ثم اضغط **Run**:
   ```sql
   CREATE ROLE midar_app WITH LOGIN PASSWORD 'كلمة-مرور-قوية-للتطبيق';
   GRANT USAGE ON SCHEMA public TO midar_app;
   ```
   يجب أن تظهر رسالة نجاح بدون أخطاء.

5. **جهّز رابط التطبيق:** خذ رابط المالك، واستبدل فيه `neondb_owner` بـ `midar_app`، واستبدل كلمة السر الطويلة بكلمة المرور التي كتبتها للتو. النتيجة:
   ```
   postgresql://midar_app:كلمة-مرور-قوية-للتطبيق@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
   **سمِّ هذا: رابط التطبيق.**

الآن عندك رابطان: **رابط المالك** (لتعديل الجداول) و**رابط التطبيق** (لتشغيل المنصة).

## الخطوة 3: إعداد المشروع على جهازك (10 دقائق)

في نافذة الأوامر داخل مجلد `midar`:

1. **ثبّت المكتبات** (تأخذ دقيقة أو دقيقتين):
   ```
   npm install
   ```

2. **أنشئ كلمة مرور لوحتك:**
   ```
   npm run owner:password
   ```
   اكتب كلمة مرور قوية (12 حرفًا فأكثر) واضغط Enter. سيطبع لك سطرًا يبدأ بـ `OWNER_PASSWORD_HASH=`. انسخه.
   > احفظ كلمة المرور نفسها عندك، لأنها لن تظهر مرة أخرى وستدخل بها.

3. **أنشئ رمز التحقق الثنائي:**
   ```
   npm run owner:totp
   ```
   سيطبع سطرًا يبدأ بـ `OWNER_TOTP_SECRET=`. انسخه، ثم افتح تطبيق **Google Authenticator** في جوالك ← إضافة حساب ← إدخال مفتاح الإعداد ← الصق المفتاح. صار عندك رمز متغير كل 30 ثانية تحتاجه عند الدخول.

4. **اختر رابطك السري:** أي كلمة طويلة يصعب تخمينها، مثل:
   ```
   /control-k29x7p4m8q
   ```

5. **أنشئ ملف الإعدادات:** في مجلد `midar` أنشئ ملفًا جديدًا باسم `.env.local` بالضبط (بنقطة في أوله)، وضع فيه:

   ```
   NODE_ENV=development
   PORT=3000
   DATABASE_URL=رابط-التطبيق-من-الخطوة-2
   MIGRATION_DATABASE_URL=رابط-المالك-من-الخطوة-2
   DATABASE_SSL=true
   OWNER_PATH=/control-k29x7p4m8q
   OWNER_USERNAME=owner
   OWNER_PASSWORD_HASH=الصق-السطر-من-الخطوة-2-بدون-الاسم
   OWNER_TOTP_SECRET=الصق-المفتاح-من-الخطوة-3
   COOKIE_SECURE=false
   TRUST_PROXY=0
   ```

   > ملاحظات: `OWNER_PASSWORD_HASH=` يأتي بعده البصمة الطويلة فقط، بدون تكرار الاسم. وهذا الملف لا يُرفع على GitHub، وهو مستثنى تلقائيًا.
   >
   > في ويندوز إذا رفض حفظ اسم يبدأ بنقطة، احفظه باسم `".env.local"` بين علامتي تنصيص.

6. **جهّز الجداول:**
   ```
   npm run migrate
   ```
   يجب أن تظهر أسطر «تطبيق 0001…» حتى «تم تطبيق 7 ترحيل».

7. **(اختياري) مدرسة تجريبية للتدريب:**
   ```
   npm run seed:demo
   ```
   سيطبع لك بيانات دخول ومعرّفات طلاب تجريبية.

8. **شغّل المنصة:**
   ```
   npm start
   ```
   افتح المتصفح على `http://localhost:3000`. الصفحة الرئيسية فاضية (هذا صحيح).
   جرّب:
   - لوحتك: `http://localhost:3000/control-k29x7p4m8q`
   - المدرسة التجريبية: `http://localhost:3000/demo`

   لإيقاف التشغيل اضغط `Ctrl + C`.

**إذا وصلت هنا فالمنصة تعمل.** الباقي رفعها للإنترنت.

## الخطوة 4: رفع الكود على GitHub (5 دقائق)

1. ادخل `github.com` ← **New repository**:
   - Repository name: `midar`
   - اختر **Private** (مهم)
   - **لا** تضع علامة على README ولا .gitignore
   - **Create repository**

2. انسخ رابط المستودع، مثل `https://github.com/USERNAME/midar.git`، ثم في نافذة الأوامر:
   ```
   git remote add origin https://github.com/USERNAME/midar.git
   git push -u origin main
   ```
   سيطلب منك تسجيل الدخول لـ GitHub. بعدها حدّث صفحة GitHub وستجد الملفات.

## الخطوة 5: تشغيل المنصة على الإنترنت عبر Render (10 دقائق)

1. ادخل `render.com` ← **Get Started** ← سجّل بحساب GitHub.

2. من اللوحة: **New** ← **Blueprint**.

3. اختر مستودع `midar`. سيقرأ Render ملف `render.yaml` تلقائيًا ويعرض خدمة باسم **midar**.

4. سيطلب منك تعبئة القيم التالية:

   | الحقل | ما تضعه |
   |---|---|
   | `DATABASE_URL` | رابط التطبيق |
   | `MIGRATION_DATABASE_URL` | رابط المالك |
   | `OWNER_PATH` | رابطك السري، مثل `/control-k29x7p4m8q` |
   | `OWNER_USERNAME` | `owner` |
   | `OWNER_PASSWORD_HASH` | البصمة نفسها من الخطوة 3 |
   | `OWNER_TOTP_SECRET` | المفتاح نفسه من الخطوة 3 |
   | `PUBLIC_URL` | اكتب مؤقتًا `https://midar.onrender.com` وستصححه بعد ظهور رابطك |

5. اضغط **Apply**. سيبني المشروع ويطبق الترحيلات ويشغّله. المدة من 3 إلى 5 دقائق. تابع السجل حتى تظهر:
   ```
   ✓ مِدار يعمل على المنفذ ...
   ```

6. في أعلى صفحة الخدمة ستجد رابط موقعك: `https://midar-xxxx.onrender.com`. افتحه، يجب أن تظهر صفحة الشعار.

7. ارجع إلى **Environment** وضع الرابط في `PUBLIC_URL`، ثم **Save** (سيعيد التشغيل تلقائيًا).

8. **إبقاء الخادم مستيقظًا:** في GitHub ← مستودع midar ← Settings ← Secrets and variables ← Actions ← تبويب **Variables** ← New variable:
   - Name: `SITE_URL`
   - Value: رابط موقعك

## الخطوة 6: أول دخول وإنشاء أول مدرسة (5 دقائق)

1. افتح `https://رابط-موقعك/control-k29x7p4m8q`.
2. أدخل `owner` وكلمة مرورك ورمز التحقق من تطبيق Authenticator.
3. تبويب **إضافة مدرسة**: اكتب اسم المدرسة، ورمزًا إنجليزيًا لها (مثل `alnoor`)، واسم مديرها، وحد الطلاب، ونهاية الاشتراك، والسعر السنوي.
4. ستظهر **بطاقة تسليم المدرسة** فيها:
   - رابط الطلاب: `https://موقعك/alnoor`
   - رمز صفحة الطلاب
   - رابط دخول المدير والمعلمين: `https://موقعك/alnoor/idara`
   - اسم المستخدم `admin` وكلمة مرور مؤقتة

   اضغط **نسخ** أو **طباعة** وسلّمها للمدرسة. كلمة المرور لن تظهر مرة أخرى.

---

## الخطوة 7: ماذا تفعل المدرسة (ترتيب العمل عندهم)

1. المدير يدخل من رابط `/idara` ويغيّر كلمة المرور من الإعدادات.
2. تبويب **الفصول والمواد**: يضيف الفصول ثم المواد.
3. تبويب **المعلمون**: يضيف كل معلم ويحدد فصوله ومواده، وتظهر له بيانات دخول المعلم.
4. تبويب **الطلاب**: يضيفهم واحدًا واحدًا، أو يلصق قائمة من Excel (اسم الطالب، اسم ولي الأمر، الجوال). كل طالب يأخذ **معرّفًا** تلقائيًا.
5. تبويب **الإعدادات**: يضيف الحساب البنكي، ويختار ما يظهر في صفحة المدرسة العامة.
6. تبويب **الجدول**: يبني جدول الحصص.
7. يوزّع على الأهالي: رابط المدرسة + رمز الصفحة + معرّف كل طالب (زر «بطاقة» يطبع بطاقة لكل ولي أمر).
8. بعدها: المعلم يسجل الحضور ويدخل الدرجات، والإدارة تعتمدها، وولي الأمر يتابع ويسدد.

## الخطوة 8 (اختيارية): نطاق خاص

1. اشترِ نطاقًا، مثل `midar.sa` من nic.sa أو أي مسجّل.
2. في Render: الخدمة ← **Settings** ← **Custom Domains** ← Add.
3. أضف سجل CNAME عند مسجّل النطاق كما يعرضه Render.
4. بعد التفعيل حدّث `PUBLIC_URL` إلى نطاقك الجديد.

## مشاكل شائعة وحلولها

| المشكلة | السبب والحل |
|---|---|
| `npm install` يعطي خطأ | نسخة Node قديمة. ثبّت Node 22 وافتح نافذة أوامر جديدة. |
| `✗ إعدادات .env غير صحيحة` | راجع الأسطر المذكورة في الرسالة. غالبًا `OWNER_PATH` قصير أو يحتوي كلمة change، أو `OWNER_PASSWORD_HASH` فارغ. |
| `✗ تعذر الاتصال بقاعدة البيانات` | رابط Neon خاطئ أو ناقص `?sslmode=require`، أو `DATABASE_SSL` ليست `true`. |
| `permission denied for table ...` | لم تُنفَّذ خطوة إنشاء `midar_app` في Neon، أو `npm run migrate` استخدم رابط التطبيق بدل رابط المالك. |
| أول فتح للموقع بطيء جدًا | الخطة المجانية تُنيم الخادم بعد 15 دقيقة. متغير `SITE_URL` في GitHub يوقظه أوقات الدوام. |
| نسيت كلمة مرور لوحتك | نفّذ `npm run owner:password` من جديد وحدّث `OWNER_PASSWORD_HASH` في Render. |
| مدير مدرسة نسي كلمته | من لوحتك ← المدارس ← «كلمة مرور جديدة للمدير». |

بعد أي تعديل على الكود:
```

git push
```
Render ينشر التحديث تلقائيًا بعد نجاح الاختبارات.
