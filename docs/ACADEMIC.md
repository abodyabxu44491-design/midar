# السجل الأكاديمي (v2.6)

مصدر واحد لبنية المدرسة. معالج أول دخول، و«الإعدادات ← السجل الأكاديمي»، وتبويب «السنة الدراسية» كلها تقرأ وتكتب نفس الجداول عبر نفس الخدمات والمسارات.

## الطبقات
| الطبقة | الملف |
|---|---|
| البيانات | `stages` ← `grades` ← `classes` (الشعب) · `subjects` + `subject_grades` · `academic_years` ← `terms` · `holidays` · `school_profile.sections_enabled` |
| الخدمات | `structure.service.js` (المراحل والصفوف والشعب والمواد والقوالب) · `academic.service.js` (السنوات والفصول والإجازات) |
| المسارات | `/api/admin/setup/*` · `/api/admin/academic/*` (للمدير فقط، ومعزولة بـ RLS) |
| الواجهة | `setup.js` (المعالج) · `academic-record.js` (الإعدادات) يعيد استخدام أجزاء `structure.js` و`academic.js` نفسها |

## الهوية الداخلية
- كل ما يُربط بالصف يُربط بـ `grade_id`/`class_id`، لا بالاسم. تغيير اسم الصف (`PATCH /setup/grades/:id`) يغيّر اسم العرض فقط، ويعيد تركيب أسماء شعبه («أول متوسط - أ»)، فيظهر الاسم الجديد في كل الأقسام.
- `POST /setup/rename-grades { grade_set }` يغيّر نمط تسمية كل صفوف المراحل الجاهزة دفعة واحدة (نفس المعرّفات). المراحل المخصصة لا تتأثر.
- لا أسماء صفوف ثابتة في الواجهات: الأنماط كلها في `academic-catalog.js` وتُستخدم عند الإنشاء فقط.

## المعالج
- المراحل اختيارية، مع مراحل مخصصة (`template.custom_stages: [{ name, grades }]`).
- المادة المختارة تُربط بصفوف المراحل التي تقترحها فقط (الفيزياء للثانوي). المادة التي لا تقترحها أي مرحلة مختارة، وكل مواد المراحل المخصصة، تُربط بكل الصفوف.
- المسودة تُحفظ في المتصفح مع كل خطوة (تحديث الصفحة لا يضيّع شيئًا)، والخطوات السابقة قابلة للضغط.
- الإنهاء (`POST /setup/finish`) معاملة واحدة: تنجح كلها أو لا يُحفظ شيء.

## السنة والفصول
- الحالة تُحسب من التواريخ ولا تُخزَّن: `upcoming` قادمة، `active` نشطة، `ended` منتهية، `archived` مؤرشفة.
- سنة حالية واحدة فقط (قيد فريد). «إضافة سنة قادمة» تُجهّزها دون أن تصبح الحالية. السنة الحالية لا تُؤرشف يدويًا.

## التدقيق
- المراحل والصفوف والشعب والمواد والسنوات والفصول والإجازات وملف المدرسة، وربط المواد بالصفوف (الترحيل 0042)، كلها في سجل العمليات بالقيمة القديمة والجديدة.
- تعديل ربط المادة يحفظ الفرق فقط (حذف ما أُزيل وإضافة الجديد).

## المدارس الحالية
لا ترحيل بيانات: البنية كانت مبنية على المعرّفات أصلًا. الترحيل 0042 يضيف trigger تدقيق فقط.

## الاختبارات
