# خارطة التنفيذ مقابل الوثيقة المعمارية

| المرحلة (من الوثيقة) | الحالة |
|---|---|
| 1) قياس الأداء | ✓ منفّذ (تقرير الأداء، Server-Timing، سجل الطلبات البطيئة) |
| 2) Local Data Layer | ✓ للمعلم: IndexedDB لكل مستخدم، احتفاظ وحذف (ADR-001) |
| 3) Operation Log + Queue + Idempotency | ✓ (ADR-002) |
| 4) Sync API + Delta + Conflict Engine | ✓ للحضور والدرجات (ADR-003/004) |
| 5) PWA Offline + Update Manager | ✓ قشرة التطبيق وتحديث آمن (ADR-005) |
| 6) الصور والملفات | جزئي: مصغرات لصور الأسئلة وكاش دائم. لا تخزين كائنات/CDN منفصل بعد |
| 7) School Local Node | ✗ تصميم مقترح فقط (ADR-007) |
| 8) Observability + Load/Stress + Failure | جزئي: مؤشرات المزامنة وقياس الطلبات؛ اختبار انقطاع وإغلاق وتكرار وتعارض (آلي وفي المتصفح). لا اختبار حمل شامل |
| 9) Feature Flags + طرح تدريجي | ✗ |
| 10) توثيق وتسليم | ✓ هذه الملفات |

**التالي بالأولوية:** توسيع العمل بدون اتصال للواجبات وملاحظات المعلم، ثم الإدارة (قراءة فقط أولًا)؛ Background Sync API؛ ثم Local Node.
**لا يعمل بدون اتصال حاليًا:** لوحات الإدارة والمحاسب، الرسوم والمالية (بحاجة لسياسة خاصة، الوثيقة §17)، إنشاء الاختبارات وإرسالها للاعتماد، الإشعارات.
