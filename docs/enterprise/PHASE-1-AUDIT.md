- `abodyabxu44491-design/midar` ظاهر لأي شخص على الإنترنت، بكل الكود والوثائق والترحيلات وتصميم الأمان، رغم أن الرخصة تنص على أنه ملكية خاصة.
- **لا أملك صلاحية تغيير الظهور**، فهو إعداد لصاحب الحساب فقط. الخطوات في القسم 3.

  - الملف كان لإبقاء Render مستيقظًا. بعد قرار البدء من الصفر على Cloudflare لم يعد له داعٍ.
  - التشغيلات الأخرى (الاختبارات، النسخ الاحتياطي، المراقبة كل 3 ساعات) تقديرها نحو 400 دقيقة شهريًا، وتبقى داخل المجاني.

## 3. خطوات GitHub عليك (لا أملك صلاحيتها)

أنفّذ بعدها ما يخص الكود. بالترتيب:

1. **اعتمد إيقاف `keepalive.yml`:** أحذفه في الفرع وتدمجه أنت، أو من GitHub: Actions ← Keep alive ← «…» ← Disable workflow.
2. **حوّل المستودع إلى خاص:** Settings ← General ← أسفل الصفحة **Danger Zone** ← **Change visibility** ← **Make private**.
3. **فعّل التحقق بخطوتين لحسابك:** Settings (الحساب) ← Password and authentication ← **Two-factor authentication**.
4. **احمِ الفرع `main`:** Settings ← Branches ← **Add branch ruleset** على `main`:
   - اطلب Pull Request قبل الدمج.
   - اطلب نجاح فحص `tests`.
   - امنع الدفع بالقوة والحذف.
5. **راجع التكاملات:** Settings ← GitHub Apps / Webhooks / Deploy keys، واحذف ما لا تعرفه. يبقى تطبيق Claude وRender، وRender حتى يُستغنى عنه.
6. **فعّل Secret scanning وPush protection:** Settings ← Code security. متاح مجانًا للمستودعات الخاصة الشخصية في بعض الخطط. وإن لم يتوفر، فالفحص الآلي في القسم 4 يغطيه.
7. *(اختياري، موصى به)* أنشئ **مؤسسة GitHub باسم الشركة** وانقل المستودع إليها (Settings ← Transfer)، حتى لا يرتبط المنتج بحساب شخصي.
