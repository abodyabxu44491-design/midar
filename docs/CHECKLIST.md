# قائمة التسليم — قبل أول مدرسة

راجع هذه القائمة مرة واحدة قبل التشغيل الحقيقي. الوقت المتوقع: نصف ساعة.

## 1) التشغيل
- [ ] `npm install` ثم `npm run migrate` بدون أخطاء.
- [ ] `npm test` → **48 اختبارًا ناجحًا**.
- [ ] فتح الموقع: الصفحة الرئيسية، رابطك السري، وصفحة مدرسة تجريبية.

## 2) الإعدادات الأساسية (من ملف `.env`)
- [ ] `OWNER_PATH` رابط طويل يصعب تخمينه.
- [ ] `OWNER_PASSWORD_HASH` من `npm run owner:password`.
- [ ] `OWNER_TOTP_SECRET` اختياري: اتركه فاضيًا للدخول باسم مستخدم وكلمة مرور فقط، أو أضفه في تطبيق Authenticator لتفعيل التحقق الثنائي.
- [ ] `COOKIE_SECURE=true` و`TRUST_PROXY` مضبوط (تحقق من `/api/owner/network`).
- [ ] `DATABASE_SSL=true` مع قاعدة بيانات مُدارة.

## 3) أول مدرسة
- [ ] أنشئ المدرسة من لوحتك، واطبع بطاقة التسليم.
- [ ] سلّم المدير بياناته — سيُطلب منه تغيير كلمة المرور عند أول دخول.
- [ ] المدير: الإعدادات ← **أقسام المنصة** (أوقف ما لا تحتاجه المدرسة).
- [ ] المدير: الإعدادات ← **استيراد البيانات** بالترتيب: الفصول، المواد، المعلمون، الطلاب.
- [ ] المدير: الإعدادات ← **طرق السداد** (الحساب البنكي وتعليمات الدفع النقدي).
- [ ] المدير: الإعدادات ← **صفحة المدرسة العامة** (ما يظهر لأولياء الأمور).
- [ ] وزّع: رابط صفحة المدرسة + رمز الصفحة + بطاقة كل طالب (من تبويب الطلاب).

## 4) الحماية
- [ ] جرّب دخولًا خاطئًا 5 مرات: يجب أن يُقفل الحساب مؤقتًا.
- [ ] جرّب فتح `/api/admin/students` بدون دخول: يجب أن يُرفض.
- [ ] جرّب فتح ملف طالب بمعرّف خاطئ: يجب أن يُرفض ويُقفل بعد محاولات.
- [ ] تأكد أن لوحة المالك لا تُفتح بدون رمز التحقق الثنائي.

## 5) النسخ الاحتياطي
- [ ] فعّل الاسترجاع الزمني في مزود قاعدة البيانات.
- [ ] **جرّب استرجاع نسخة مرة واحدة فعليًا** قبل إدخال بيانات حقيقية.
- [ ] خذ نسخة يدوية: الإعدادات ← البيانات والاشتراك ← تصدير نسخة كاملة.

## 6) أمور قانونية
- [ ] مراجعة نظام حماية البيانات الشخصية (PDPL) مع مختص.
- [ ] إبلاغ المدرسة بأن حالة السداد لا تُعرض للجميع إلا إذا فعّلتها بنفسها.
